Malicious Code Smuggled Into Website Testing Tool Reached 178 Organisations

Attackers turned a widely used website testing service into a channel for malicious code on Monday, reaching the websites of 178 organisations, including some of the most visited sites on the internet, security researchers have found.

Researchers at Report URI examined 1,611 snippets of code from Optimizely Web Experimentation, a service companies use to test changes to their web pages, and found 188 carrying the injected code. The affected organisations include Zoom, the BBC, CNN, Salesforce, GitLab, IKEA, HSBC, Equifax, Air France-KLM, Ledger and Peacock. The findings do not show that those companies' own systems were broken into, or that every visitor was harmed.

The code was built to steal payment card details, replace cryptocurrency wallet addresses so money went to the attackers instead, and take cookies and screenshots of what visitors saw. On Apple phones and tablets it also tried to deliver software designed to break into the device. The researchers counted about $7,040 in cryptocurrency reaching wallets controlled by the attackers within about nine hours. How many cards or accounts were affected is not yet known.

The attacker got in through a flaw in Optimizely's process for signing up new accounts, and used it to write code into the custom-code field of existing customers' projects. Because the files were served from Optimizely's own servers, with a valid security certificate, browsers and security filters treated them as trusted. The first trace was found in the BBC's snippet at 04:21 UTC on Monday, and the main payload was rebuilt 26 times during the day as the attacker added features and wallet addresses.

Optimizely confirmed the incident early on Tuesday, saying the vulnerable path had been blocked, the injected code removed and affected customers contacted directly. Its investigation is continuing and the incident is still listed as being monitored. By late on Monday evening only one of the 188 snippets still carried the code. Optimizely has not said how a flaw in signing up new accounts gave access to existing customers' projects, how many customers were affected, or whether any data it holds was accessed. No attacker has been publicly named. One independent researcher has called the campaign OPTIMJACK. HSBC's security settings blocked the main payload, although backup code still ran on the page.

Key points

  • Security researchers found injected code in 188 of 1,611 Optimizely snippets they checked, spread across 178 organisations.
  • The code skimmed payment cards, swapped cryptocurrency wallet addresses and stole cookies and screenshots; about $7,040 in crypto reached the attackers within nine hours.
  • Optimizely says a flaw in its account signup flow let the attacker alter customer projects, and the files were served from its own servers with a valid certificate.
  • Optimizely says the flaw is blocked and the code removed, but has not said how many customers were hit or whether data it holds was accessed.
